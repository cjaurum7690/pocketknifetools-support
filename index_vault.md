# PocketKnife Vault
PocketKnife Vault is a free, offline password manager that keeps your credentials locked on your device — no cloud account, no subscription, no compromises.

## Features
Security & Authentication
 - Face ID and Touch ID biometric unlock
 - Device passcode fallback when biometrics aren't available
 - Auto-locks the moment the app leaves the foreground
 - Re-authenticates automatically when returning to the app
 - Privacy screen covers all vault content during app switching, Control Center, and incoming calls — the iOS app switcher never captures your data

Encryption & Storage
 - Passwords stored exclusively in the iOS Keychain — hardware-backed, never written to disk
 - All metadata (descriptions, usernames, URLs, notes) encrypted with AES-256-GCM before being saved
 - Unique encryption key generated per device, stored in the Keychain, never transmitted
 - Fully on-device — no server, no cloud account, no sign-up required
 - Database excluded from iCloud and iTunes backups

Vault Organization
 - Unlimited entries
 - Organize entries into named groups
 - Reorder groups to match your workflow
 - Each entry stores: description, username, password, URL, and free-form notes
 - Rename or delete groups at any time; entries move with the group

Password Generator
 - Cryptographically secure random generation (no predictable patterns)
 - Configurable length from 12 to 32 characters
 - Toggle uppercase letters, numbers, and symbols independently
 - Regenerate instantly with one tap
 - Preview the generated password before using it

Clipboard
 - One-tap copy for usernames, passwords, and URLs
 - Clipboard auto-clears after 120 seconds
 - Live countdown banner shows exactly how long remains
 - "Clear now" button to wipe the clipboard immediately
 - Clipboard also clears automatically when you navigate away from an entry

Privacy Controls
 - Hide usernames in the entry list with a single tap — protects against shoulder surfing while browsing
 - Preference is saved across sessions
 - No analytics SDK, no crash reporting, no advertising framework
 - Zero network requests — the app has no internet code whatsoever

Interface
 - Supports iOS Light and Dark mode
 - Portrait orientation optimized for one-handed use
 - Clean, minimal design with no clutter
 - Free — no subscription, no in-app purchases, no upsells
